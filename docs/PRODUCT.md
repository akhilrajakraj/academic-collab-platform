# Product direction

## Target users
- Students working on academic projects
- Project teams writing reports together
- Supervisors/reviewers

## Differentiator
This is not intended to be a clone of Microsoft Word. The product focuses on academic project collaboration: assigning sections, tracking contributions, reviewing work, assembling a final document, and exporting it in common formats.

## Future Microsoft layer
A Microsoft Word Add-in and/or Microsoft Graph integration can be added later. The platform should remain functional without Microsoft services.
