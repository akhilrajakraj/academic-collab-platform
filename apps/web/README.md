# Web application

Next.js App Router dashboard for Academic Collab Platform.

## Current slice

The overview page includes workspace navigation, project/document summaries, recent activity, document search and status filters, and a create-document dialog. It is a UI preview: created documents live only in client-side state and are not persisted or shared with collaborators yet.

## Development

Run the web workspace's dev script from the repository root after installing dependencies. The app defaults to port 3000.
